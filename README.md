# RS-FSXCS-N01-3HP-EX: прошивка для ESP32-S3

Минимальная прошивка опрашивает метеостанцию Renke по Modbus RTU и печатает в USB Serial ветер, температуру, влажность, давление, освещённость и дождь. Аппаратная основа и код обмена взяты из соседнего проекта `smart_seedling_nursery`. Прошивка **только читает** регистры, настройки и калибровку станции не меняет.

## Подключение

Текущая конфигурация рассчитана на ESP32-S3 Super Mini и SparkFun BOB-10124 (SP3485): GPIO5 → TX/DI, GPIO6 ← RX/RO, GPIO13 → RTS (DE и /RE вместе), 3,3 В → VCC трансивера, общая земля → GND. Линии станции RS-485 A/B соединяются с A/B трансивера. Метеостанции требуется **отдельное питание 10–30 В DC**; 3,3 В с платы ESP32 на её питание не подавать. Сверить назначение проводов с кабелем конкретного экземпляра. В руководстве V1.8 указаны коричневый `+V`, чёрный `GND`, жёлтый/зелёный `A`, синий `B`.

Адрес `1` и скорость `4800` бод заданы в [`firmware/src/main.rs`](firmware/src/main.rs). Это заводские значения по руководству. На общей шине адрес каждого устройства должен быть уникальным; если адрес или скорость менялись, исправить обе константы до прошивки.

## Сборка и запуск

Нужны Rust toolchain `esp`, target `xtensa-esp32s3-none-elf` и `espflash`, как в `smart_seedling_nursery`.

```sh
cd firmware
export PATH="/home/kraft/.espressif/tools/xtensa-esp-elf/esp-13.2.0_20240530/xtensa-esp-elf/bin:$PATH"
cargo build --offline
cargo run --offline --release
```

Путь к Xtensa linker указан для этой машины; на другом компьютере он может отличаться. `cargo run` запускает `espflash flash --before default-reset --monitor`. Подключённая станция уже выдаёт показания Modbus; пользователь подтвердил скорость ветра, силу и направление, температуру, влажность, давление, освещённость и дождь.

## Данные Modbus

Читаются holding-регистры **500–513** (`0x01F4–0x0201`) одной командой `0x03`; это адреса в запросе Modbus, а не PLC-обозначения `40501–40514`. Из ответа выбираются:

| Регистр | Значение | Масштаб |
|---:|---|---:|
| 500 | скорость ветра | 0,1 м/с |
| 501 | сила ветра | целое |
| 502, 503 | направление: сектор 0–7 и градусы | целое |
| 504, 505 | влажность и температура (знаковая) | 0,1 %RH и 0,1 °C |
| 509 | давление | 0,1 кПа |
| 510–511 | освещённость, старшее слово первым | 1 лк, `u32` |
| 512 | альтернативная освещённость | 100 лк |
| 513 | показание дождя | 0,1 мм |

Руководство V1.8 для серии `RS-FSXCS-N01-*-EX` описывает вариант `3HP` и эти регистры: [оригинал PDF производителя](https://www.laskakit.cz/user/related_files/renke-rs-fsxcs-n01-ultrasonic-wind-speed-sensor-v1-8-cn.pdf). Более старое руководство V1.2 указывает иной масштаб скорости ветра (×100); если показания вашей партии отличаются в 10 раз, нужно сверить версию паспорта и фактические значения. Семантика показания дождя (накопление или иной интервал) в таблице не уточнена, поэтому прошивка выводит его без вычисления интенсивности.

При `Timeout` проверить адрес/скорость, питание 10–30 В, общую землю и A/B. При `Crc` проверить полярность и топологию RS-485. Ошибки выводятся в монитор, предыдущие показания не выдаются как свежие.

## Wi-Fi, отправка и Grafana

Каталог [`firmware_wifi`](firmware_wifi/README.md) содержит отдельную сборку
ESP-IDF для ESP32-S3: она снимает показания раз в 20 минут, отправляет их в
AFC по MQTT/TLS и затем переводит ESP32 в глубокий сон. Станция Renke остаётся
на отдельном питании. При первом запуске Wi-Fi настраивается через точку доступа
`Weather-Setup`; MQTT-реквизиты выдаёт регистрационный скрипт AFC.

Grafana-шаблон с компасной шкалой ветра для нового scope находится в
[`grafana/dashboard-templates/ultrasonic-weather-station-basis-full.json`](grafana/dashboard-templates/ultrasonic-weather-station-basis-full.json).
Целевой scope станции — `basis / vostochnoe / first_pear_nursery`;
порядок переноса и проверки описан в Wi-Fi README.

Компас использует подписанную панель Business Charts
(`volkovlabs-echarts-panel`, версия `6.6.0`, установлена на AFC с Grafana 11.2).
При переносе на новый сервер установите её через
`grafana cli plugins install volkovlabs-echarts-panel 6.6.0` и перезапустите Grafana.
Код отрисовки находится в [`grafana/wind-compass.js`](grafana/wind-compass.js)
и встроен в `options.getOption` панели с `id: 1` в JSON-шаблоне; при изменении
кода обновляйте также эту копию. Компас показывает С/В/Ю/З, скорость в центре
и угол датчика стрелкой, включая 0° на север при нулевой скорости.

### Wi-Fi с постоянным питанием от сети

В [`firmware_wifi`](firmware_wifi/README.md) добавлен режим `mains-powered`:
чтение и отправка раз в 20 минут без глубокого сна и ключей питания.
Сборка: `cargo +esp build --release --features mains-powered` из `firmware_wifi`
с настроенным ESP-IDF окружением. GPIO13 по-прежнему управляет направлением RS-485.
